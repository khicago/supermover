# macOS file access constraint summary

## What This Is

- source id: `ap01`

## Why It Matters

A migration app touches user data, removable volumes, and network volumes, all of which can require explicit user consent on modern macOS.

## Borrow
- Make source/target path selection and permission readiness a first-class onboarding step.

## Avoid
- Do not defer permissions to final packaging or treat path strings in profiles as sufficient runtime access.

## Bagakit Implication
- The app plan needs sandbox/full-disk-access/security-scoped-bookmark stance, failure copy, and permission smoke tests.

# Code of Conduct

Supermover contributors are expected to keep project discussion technical,
respectful, and safety-focused.

## Expected Behavior

- Be direct and constructive.
- Assume good intent, but correct unsafe claims quickly.
- Keep migration, deletion, security, and release-readiness discussions grounded
  in evidence.
- Redact private paths, secrets, device identifiers, and personal data from
  public reports.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private security details before maintainers can investigate.
- Encouraging users to run unsafe migration, prune, network, or release steps
  outside the documented boundaries.
- Presenting planned behavior as implemented behavior.

## Enforcement

Maintainers may edit, hide, or close issues and pull requests that violate this
code of conduct. Repeated or severe violations may result in a ban from project
spaces.

Security-sensitive reports should follow [SECURITY.md](SECURITY.md), not public
issue threads.
